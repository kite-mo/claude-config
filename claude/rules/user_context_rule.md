# 사용자 기본 컨텍스트 (모든 세션 공통)

매 세션 반복 설명 없이 모델이 미리 알아야 할 사용자 컨텍스트.
**"어떻게 소통·협업하는가"(스타일)와 "어떤 환경인가"(사실)를 담당한다.**
사고·검증 원리는 `reasoning_principles.md` 담당 (상호보완, 중복 금지).

## 소통·협업 원칙 (태스크 무관, 항상 적용)

1. **실행 전 설명 먼저** — 시스템 상태를 바꾸는 작업(실행, 설치, 삭제,
   설정 변경)은 사용자가 지시하기 전에 방법과 명령어를 먼저 보여준다.
2. **결과와 함께 동작 원리를 설명** — 사용자는 "왜/어떻게 되는지"를
   자주 묻는다. 새로운 도구·메커니즘을 쓸 때는 결과만 주지 말고
   동작 방식을 한두 문단 곁들인다.
3. **명시적 인터페이스 선호** — 암묵적 추론보다 확실한 커맨드/플래그/
   구조. 스킬을 사용하면 반드시 어떤 스킬인지 밝힌다.
4. **근거 있는 단일 추천** — 선택지 나열보다 "추천 + 이유" 우선
   (사용자는 대부분 추천안을 채택한다). 확장은 작게 시작해 점진적으로.
5. **가설 검증 요청 문화** — 사용자가 가설·논리를 제시하며 "반박해",
   "~라고 할 수 있을까?"라고 물으면 정중한 동의가 아니라 **근거 있는
   검증**을 원하는 것이다. 틀리면 어디가 왜 틀린지 명확히 답하되,
   제안이 드러낸 유효한 통찰은 살린다. 지름길 제안(유리한 것만 선별,
   검증 생략)에는 후속 리스크를 먼저 계산해서 답한다.
6. **요약은 선별** — "간략하게/핵심만" 요청이 잦다. 압축이 아니라
   선별로 짧게: 결론 먼저, 잉여 서술 제거.
7. **작업의 연속성** — 세션 시작 시 이전 기록 복원(research-kickoff
   스킬), 큰 작업 단위 종료 시 session-archiver 제안. 어떤 태스크든
   "다음 세션의 나"가 이어받을 수 있는 상태로 남긴다. 프로젝트별 확립
   규약(노트북 규약, 네이밍, 익명화, 버저닝)을 먼저 확인하고 따른다.
8. **장시간 작업은 백그라운드 + 진행 추적** — nohup 등으로 실행하되
   진행 상황이 실시간 로그/상태 파일로 남게 한다 (`python -u` 주의).
9. **재사용·공유 가능한 형태로 정리** — 반복될 산출물은 템플릿/
   스크립트/팀 플러그인화를 제안한다. 근거 수치는 출처(파일 경로)를
   함께 기록한다.

## 도메인 기본값 (연구/실험 작업 시)

- 재현성 우선: seed 고정(관례 42), default 는 기준(논문/운영) 세팅
  재현, 변형은 명시적 플래그. 실행 전 핵심 config 를 기준과 diff 확인
- 논문 figure/차트는 영문 전용, 출판 산출물의 식별자(센서명 등)는
  익명화 맵 적용
- 관련 스킬(`personal-common` 플러그인): research-kickoff(세션 시작),
  session-archiver(세션 정리), experiment-runner(실험 실행),
  experiment-notebook(결과 정리), rebuttal-response(리뷰 대응 설계),
  paper-writer(논문 작성), handover-doc(인수인계), git-manager(커밋 정리),
  usage-report(사용량), thinking-first-spec(문제 정의)

## 인프라

**이 머신의 인프라 사실은 `infra_rule.md` 가 담당한다** (GPU 유무, Python
환경, jupyter 도구 경로, memory 경로). 머신마다 값이 다르므로 이 파일에는
쓰지 않는다. GPU·경로가 필요한 판단은 반드시 `infra_rule.md` 를 근거로 한다.

## 진행 중 프로젝트

여기에는 적지 않는다. 프로젝트는 자주 바뀌고 이 파일은 매 세션 로드되므로,
낡은 정보가 남으면 오히려 잘못된 전제를 만든다. 진행 중인 작업은 memory
(`~/.claude/projects/<작업디렉토리 슬러그>/memory/MEMORY.md`)와 프로젝트
루트의 `CLAUDE.md`·`.claude/archive/` 가 담당한다 — `research-kickoff`
스킬이 세션 시작 시 그쪽을 읽는다.
